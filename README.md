# ICM42688-MMC5603 9-Axis Gyroscope

本项目是一个基于ICM42688和MMC5603传感器的9轴陀螺仪驱动和应用示例。工程主要使用C语言编写，包含相关驱动、应用代码，以及基本的构建脚本和部分HTML展示。

## 项目介绍

- **ICM42688**：一款高精度的6轴惯性传感器，集成了陀螺仪和加速度计。
- **MMC5603**：三轴磁力计，可与ICM42688组合，实现完整的9轴姿态感知。
- 本工程实现两种传感器的数据采集、处理与融合，为开发嵌入式运动检测、方向定位、姿态估算等应用提供基础。

## 主要功能

- ICM42688与MMC5603传感器驱动
- 9轴姿态数据融合（陀螺仪、加速度计、磁力计数据处理）
- 数据输出接口（串口通信等）
- 示例应用（运动检测，方向估算等）

## 文件说明

- `src/`：主要的C代码，包括传感器驱动、数据处理、应用例程
- `Makefile`：工程构建脚本，使用make进行编译
- `html/`：部分展示网页或说明文档
- 其他：配置文件、文档及工具说明

## 使用方法

1. 克隆本仓库
   ```bash
   git clone https://github.com/AngRelia/ICM42688-MMC5603-9-axis-gyroscope.git
   ```
2. 编译工程（需安装gcc，make等工具）
   ```bash
   cd ICM42688-MMC5603-9-axis-gyroscope
   make
   ```
3. 按照硬件连接说明，将ICM42688和MMC5603接入微控制器
4. 启动程序，通过串口等方式读取数据

## 相关依赖

- gcc编译器
- make工具
- 嵌入式开发板（如STM32、Arduino等，具体硬件需求请参考代码中相关说明）
